# Antigravity CLI Hooks

`keepygaga install --yes --host antigravity` projects one Context Bootstrap command at `PreInvocation` into `~/.gemini/config/hooks.json` under `shared-context-bootstrap`. Its output combines the live Profile and Preferences pages, scope-routing guidance, and the routing/completion reminder in one injected message. Setup removes the obsolete standalone route command while preserving unrelated Hooks.

Antigravity CLI is not Gemini CLI. Keepygaga does not project PostToolUse or Stop reminders.
