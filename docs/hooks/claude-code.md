# Claude Code Hooks

`keepygaga install --yes --host claude-code` projects Context Bootstrap at SessionStart and SubagentStart, a stateless Memory Route reminder at UserPromptSubmit, and recovery guidance at SessionStart with source `compact`. Both startup events read the same live Profile and Preferences pages with scope-routing guidance.

Commands use the installed `keepygaga` launcher and current absolute config path. Setup removes obsolete Keepygaga PostToolUse closeout commands while preserving unrelated matchers and commands.
