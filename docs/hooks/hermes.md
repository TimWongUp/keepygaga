# Hermes Hooks

`keepygaga install --yes --host hermes` projects one Context Bootstrap command at `pre_llm_call` within `~/.hermes/config.yaml`. The first turn receives the live Profile and Preferences pages, scope-routing guidance, and the routing/completion reminder in one `context` payload. Because Hermes replays persisted injected context, a later turn (`extra.is_first_turn` is `false`) whose reported history still carries that bootstrap receives only the reminder; a later turn whose history no longer holds it — for example a session path that does not persist injected context — receives the full bootstrap again. A payload without `extra.is_first_turn` set to `false` receives the full bootstrap.

Hermes `subagent_start` is an observer event whose return value is ignored; it is not a context-injection surface. Keepygaga does not project a separate closeout event. Round-trip YAML merging removes obsolete Keepygaga-owned closeout and standalone route projections while preserving unrelated keys, comments, ordering, and Hook entries.
