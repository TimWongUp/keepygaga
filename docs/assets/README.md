# Brand assets

This directory is the repository authority for Keepygaga product and
promotional images. Preserve the source product logo when producing derived
assets; do not redraw or overwrite it.

## Product brand

- `keepygaga-logo.png` — canonical Keepygaga product logo, 1254×1254 RGBA.
- `keepygaga-banner.svg` — editable English README banner.
- `keepygaga-banner.png` — rendered 1280×640 English README banner.
- `keepygaga-banner.zh-CN.svg` — editable Simplified Chinese README banner.
- `keepygaga-banner.zh-CN.png` — rendered 1280×640 Simplified Chinese README
  banner.

## Personal brand

- `tim-wong-mark.png` — project-local copy required to render the README
  banners. The canonical personal-brand collection is maintained outside this
  repository.

The README banners use the canonical product logo without redrawing it and
place the white-and-green personal mark on the small dark badge treatment in
the upper-left corner.
